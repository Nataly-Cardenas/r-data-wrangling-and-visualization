# Data Wrangling and Visualization in R

A collection of data analysis exercises in R, published as an interactive
book with bookdown. Each chapter takes a real dataset, cleans and
transforms it, and presents the results through clear visualizations.

 **Read the book:** https://nataly-cardenas.github.io/r-data-wrangling-and-visualization/

## Run it locally

1. Clone the repository:
```bash
   git clone https://github.com/nataly-cardenas/r-data-wrangling-and-visualization.git
```
2. Open the `.Rproj` file in RStudio.
3. Install the required packages.
4. Build the book with `bookdown::render_book("index.Rmd")`.
